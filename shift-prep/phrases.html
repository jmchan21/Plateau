JMC Dot Phrases

Personal add-ons to the UCI department templates. Attestations always use UCI's approved versions. 30 phrases, generated from shift-prep/SMARTPHRASES.md.

Loading each phrase into Epic
  1. Epic menu, then SmartPhrase Manager, then New.
  2. Tap Copy name and paste it as the phrase name (Epic drops the leading dot).
  3. Tap Copy text and paste into the editor.
  4. Check the @TOKEN@ links resolve (they turn into fields). If one doesn't, delete it and type @ to search for UCI's version.
  5. Options in {a/b/c} paste as plain text. Either build them into a SmartList, or leave them and delete the unused options each time you write.
  6. Accept, then tick the box on the card. Ticks are saved in this browser only.
